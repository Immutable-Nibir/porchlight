Porchlight is a minimalist, local-first micro-social media platform running entirely inside a single .html file. It requires no backend, build tools, framework dependencies, or external libraries.  
​Key Features
​100% Single-File App: Complete interface, styling, client logic, and database operations reside in one standalone file.  
​Local-First Storage: User accounts, feeds, likes, and image uploads persist across sessions directly inside browser IndexedDB storage.  
​Interactive Image Cropper: Native canvas cropper supporting drag-to-position, mouse wheel zoom, and multi-touch pinch gestures for avatars and profile banners.  
​Media Compression & GIF Support: Automatically resizes standard post photos to keep storage footprint minimal while preserving animated GIFs.  
​Web Crypto Auth: Client-side authentication powered by salted SHA-256 password hashing via the Web Crypto API.  
​Adaptive Theme: Clean responsive layout featuring automatic light and dark mode switching (prefers-color-scheme).  
​Keyboard Shortcuts: Fast navigation for desktop users (H for Feed/Shuffle, U to post, P for Profile, and Ctrl/Cmd + Enter to submit posts).
